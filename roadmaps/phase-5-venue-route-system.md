# Phase 5 — Venue and Route System

## Goal
Support one or more destinations and movement between them, with host-controlled progression.

## Systems to define
- venue lists (single vs multi-destination)
- route flow (host-defined order + dynamic adjustments)
- check-ins at venues
- side quests per venue (optional challenges)
- transitions between destinations (timing + host actions)
- progress tracking (attendee + host views)

## Route flexibility
- host must be able to adjust in real-time
- guests follow the host’s current active step

## Phase 5 open decisions
- time gating for check-ins
- how venues unlock content/game rounds
- how to represent side quests and completion
