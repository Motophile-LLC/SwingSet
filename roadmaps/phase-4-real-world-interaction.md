# Phase 4 — Real-World Interaction Layer

## Goal
Define verification and proximity mechanics so “nearby + verified meet” works reliably.

## Systems to define
- QR
- NFC
- Bluetooth proximity discovery
- proximity hints/thresholds (what counts as warm vs far)
- verification flow (what must happen for unlock)
- fallback behavior when hardware fails

## Interaction principle
- Attendees should be guided to real-world actions
- Verification should be consentful and minimize sensitive data exposure

## Phase 4 open decisions
- exact verification thresholds and UI messages
- device compatibility strategy and fallbacks
- data kept locally vs stored server-side
