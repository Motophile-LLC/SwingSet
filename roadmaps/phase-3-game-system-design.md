# Phase 3 — Game System Design

## Goal
Define each game’s objective, user interaction, scoring, and round lifecycle so hosts can run events smoothly.

## Candidate game systems
- Chameleon Color Match
- Trait Hunt / Human Bingo
- Trivia / icebreaker rounds
- Photo prompt rounds
- Venue side quests
- Partner regroup / check-in
- Verified meet / contact exchange unlock

## For each game (what we must define)
- Objective: what success means
- User-facing UI: what attendees see
- Actions: what attendees do (tap, verify, answer, move)
- Verification: how NFC/Bluetooth/QR contributes (when applicable)
- Scoring rules: points awarded and why
- Round lifecycle: start, active state, end conditions
- Host controls: what host can change live

## Scoring philosophy
- Encourage movement + conversation
- Reward participation and successful verified interactions
- Keep rules explainable in seconds

## Phase 3 open decisions
- final list of shipped game modes for v1
